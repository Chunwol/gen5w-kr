# What the head unit accepts, checked against its own toolbox and mksh R43.
#
#   <command> <option> ...     a toolbox applet and the exact option words it accepts
#   !<command> <reason>        never use this command in on-unit scripts
#
# A toolbox applet (marked in commands.txt) with no line here takes no options.
# Other programs in commands.txt (am, pm, settings, logcat, ...) are not checked.
# mksh R43 builtins (print, echo, read, test, cat, sleep, kill, realpath, ...) are fine.
#
# Verified on the unit's toolbox:
#   mv     takes no options: "mv -f a b" fails on '-f'. Plain mv already replaces
#          an existing target (rename()), and moves into an existing directory.
#   cmp    has no -s; "cmp a b >/dev/null 2>&1" gives 0 same / 1 different or missing
#   id     ignores -u and prints the full id line
#   printf, head, tail, cut, sed, tr, awk, wc, sort, find, stat, md5sum, basename,
#   dirname, mktemp, seq, expr, xargs, tee, timeout, env do not exist

mv
cmp
cp -p -R
rm -f -r -rf
mkdir -p
grep +aqxFEcvnoi
ls -l -n -ln
ln -s
id
