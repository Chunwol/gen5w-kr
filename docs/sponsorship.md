# 개발 후원

수신 페이지: **[Chunwol GitHub Sponsors](https://github.com/sponsors/Chunwol)**

저장소의 `.github/FUNDING.yml`에 `github: [Chunwol]`을 설정했습니다. GitHub의 Sponsor 버튼과 한국어 README의 후원 링크는 위 페이지를 사용합니다. 2026-10-27 GitHub API에서 Sponsors listing 활성화를 확인했습니다.

후원은 선택이며 앱 이용료·수리·특정 차종 지원·일정 보장·검토 우선권의 대가가 아닙니다. 기여와 오류 보고는 후원 없이 가능합니다.

GitHub README는 iframe을 표시하지 않으므로 카드 iframe 대신 링크를 사용합니다. GitHub 밖의 웹페이지에서는 사용자가 만든 아래 카드를 사용할 수 있습니다. 저장소에서 웹사이트를 별도로 발행한 것은 아닙니다.

```html
<iframe src="https://github.com/sponsors/Chunwol/button" title="Chunwol 개발 후원" height="32" width="114" style="border: 0; border-radius: 6px;"></iframe>
<iframe src="https://github.com/sponsors/Chunwol/card" title="Chunwol 후원 카드" height="225" width="600" style="border: 0; max-width: 100%;"></iframe>
```
