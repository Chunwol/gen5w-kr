# V039 범용판 실차 시험 후보 검토

2026-11-20. 패키지 버전 0.3.81. 실차 기능 검증이 끝난 판이 아니다.

후보 ZIP(감사 61파일)의 SHA256은 릴리스 v0.3.81-rc.1의 `RELEASE-SHA256SUMS`에 있다.
제조사 펌웨어나 라이브러리는 배포하지 않는다. 차량의 원본으로 준비한다.

## 이번 수정의 근거

1. **0.3.77 홈 화면 실패.**
   - 오래된 훅이 `-Xbootclasspath/a`를 붙여 공유 dex cache를 다시 썼고, 그 결과 SIGBUS가 났다.
   - 빌드 해시 게이트, 실행 중 bootclasspath 검사, 래퍼 fail-open으로 막는다.
   - VM 시험 `BootPathVmTest`로 확인한다.
2. **0.3.79 설치 거부.**
   - 앱만 삭제돼 `/system` 변경이 남아 있었다.
   - 설치기가 기기 안의 부트 가드로 순정 복구한 뒤 재부팅하고, 다음에 꽂으면 설치한다.
   - 이미 순정인데 래퍼만 남은 경우에는 재부팅을 반복하지 않는다.
3. **블루투스와 CarPlay 동시 연결.** 0.3.70~0.3.78의 `onDisableBluetooth` 억제를 없앴다.
4. **iAP2 링크 실패.**
   - 순정 서버(디컴파일로 확인)는 연결 확인 패킷을 `connected()`보다 먼저 보낸다. 이 패킷을 버리던 동작을 고쳤다.
   - 링크 실패 전체의 원인인지는 실차 로그(`path=cp5`)로 확인해야 한다.

## 확인 결과

- 셸 전체 회귀(`tests/run-shell.sh`)가 rc=0으로 통과했다. 같은 셸에서 bash 5.3 EXIT trap이 종료 코드를 숨기던 문제를 고친 뒤 돌렸다.
- 중계 32개, 어댑터, USB 설치기 21개, 범용판 UI, 설치 후처리, 후보 조립 시험이 통과했다.
- 동의 화면 34개, 블루링크 44개 시험이 통과했다.
- 차량 Dalvik VM: 디스패치, 앱 로컬 엔진, 캐시 미변경, bootclasspath 유지, DiPO 훅 18개 확인을 통과했다.
- 순정 `WifiSettings.odex`에 핫스팟 패치를 적용한 결과는 `fa73f5cc…`다. 시험판 레시피의 결과 해시와 같다.

## 실차에서 남는 범위

- 남은 설치 복구와 재부팅, 설치 후 홈 화면.
- 무선 CarPlay의 블루투스 넘김, 소리, HUD, INFO, 통화.
- 동의 화면, 블루링크, 핫스팟 스위치.
- 부트 가드와 USB 응급 복구의 실제 동작.

절차는 [실차 확인 목록](portable-vehicle-checklist.ko.md)에 있다.
