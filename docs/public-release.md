# 공개 준비

저장소는 현재 비공개입니다. 기본형의 순정 안내 즉시 자동 전환와 원복 기능을 구현했습니다. 이전 개인용 생략 구성은 로컬로 분리하며, 기존 원격 이력·릴리스·CI 산출물도 공개 전에 정리해야 합니다.

## 점검 항목

| 항목 | 기준 |
|---|---|
| 한국어 안내 | 설치·사용·차종 요청·오류 제보 경로 연결 |
| 배포 버전 | 기본형·동글형 (지원 사양의 버튼 활성화 즉시 순정 자동 전환) |
| 진단 로그 | 기능별 결과와 허용한 기기 정보만 수집 |
| 라이선스 | GPL-3.0-only 전문, NOTICE.md 및 대응 소스 제공 |
| 배포 파일 | 같은 커밋의 기본형·동글형 ZIP·소스·RELEASE-SHA256SUMS |
| 후원 | GitHub Sponsors 수신 페이지와 FUNDING 연결 |
| Git 이력 | 제조사 바이너리·개인 키·비밀 패턴 검사 |

설치 ZIP에 들어가는 안내도 CI에서 다시 묶어 확인합니다. 개인용 생략 구성이 들어간 이전 릴리스·소스 산출물은 로컬 보존 후 원격 배포에서 내립니다. 이전 Git 이력을 그대로 공개하지 않습니다. 자동 검색만으로 모든 권리나 개인정보의 부재를 증명하지는 않습니다.

## 공개할 때 할 일

1. 저장소 공개 범위를 Public으로 전환합니다.
2. **Security → Private vulnerability reporting**을 활성화합니다.
3. `main`의 force push·삭제 금지를 설정합니다. 현재 비공개 요금제에서는 브랜치 보호 API가 HTTP403을 반환합니다.
4. 로그아웃 상태에서 README, 기본형·동글형 설치 ZIP, 소스 ZIP, 체크섬, 이슈 양식과 후원 링크가 열리는지 확인합니다.
5. 검토한 초안 릴리스를 게시합니다.

차량별 지원·확인 범위는 [지원 안내](porting.md)와 [검증 범위](validation.md)를 따릅니다. 공개 전환 자체가 지원 차량을 늘리거나 실제 차량 확인을 대신하지는 않습니다.
