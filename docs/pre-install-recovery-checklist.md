# 설치 전 복구 준비 체크리스트

> ## ⚠️ 메인보드(헤드유닛) 교체 위험 — 반드시 읽으세요
> 이것은 **실차 미검증 실험**입니다. **설치 후 조금이라도 부팅이 비정상(현대 로고 반복·꺼짐 반복 등)이면, 자동 복구·공식 SW 업데이트·물리 복구로도 되돌릴 수 없는 경우 메인보드(헤드유닛) 교체 외에 방법이 없을 수 있습니다. 실제로 그렇게 통교체한 사례가 있었습니다.** 교체 비용과 위험을 전부 감수할 수 있고, 아래 복구 준비를 **모두** 마친 경우에만 진행하세요. 조금이라도 불안하면 설치하지 마세요.

부트가드(자동 복구)는 **소프트웨어 실패 + 가드가 부팅을 셀 수 있을 때만** 작동한다. 가장 이른 사망(NEMESIS 서비스가 뜨기 전 재부팅)·전원·eMMC·부트로더 손상은 못 막는다. 따라서 **실차 설치 전에 아래를 반드시 준비**한다 — "알아서 고쳐지길 희망"하는 대신 "깨져도 내가 되살린다"로.

## 설치 전 (건강한 유닛에서)

- [ ] **순정 복원 USB 준비**: 받은 ZIP과 **호환되는 번들**(그 버전의 `remove.sh`/검사된 제거 훅 포함)을 USB에 보관. `/data` 초기화로 NEMESIS 등록이 사라져도 번들의 제거 훅으로 내구성 백업을 복원할 수 있음(`docs/recovery.md`). 단 `/system` 원본까지 지워진 **펌웨어 교체 상황은 이 경로로 복구 불가**.
- [ ] **공식 SW 업데이트 USB 준비**: 순정 V039 공식 펌웨어 USB. 이게 진짜 "초기화=순정 복귀" 경로(= /system 통째 교체). 소프트 문제는 대개 이걸로 복구됨.
- [ ] **recovery 진입 검증(건강할 때)**: `adb reboot recovery`로 순정 recovery가 뜨는지 확인. 뜨면 Android층 벽돌은 복구 가능이 **보장**됨.
- [ ] **PC fastboot/UART 경로 확인**: `docs/bootloader-recovery.md`의 읽기 전용 probe로 fastboot가 실제 열거되는지 확인(열거 안 되면 그 경로는 이 유닛에서 미지원). UART 접점·전압은 별도 확인.
- [ ] **벤치 선검증**: 가능하면 **차 말고 중고 유닛**에서 설치→재부팅→제거 전체 사이클을 먼저 돌림.

## 설치 직후

- [ ] 설치 자동 재부팅(warm) 후 정상 부팅·CarPlay·안내 확인.
- [ ] **다음 콜드 시동(key off→on)까지 정상인지 확인** ← 벽돌이 난 지점. 여기서 logo→꺼짐이면 즉시 중단하고 복구 USB 사용.

## 벽돌 증상별 대응

| 증상 | 1차 대응 |
|---|---|
| UI 잠깐 떴다가 꺼짐 | 복구 USB(제거 훅) → 순정 복원 |
| **logo→꺼짐(UI 전), 반복** | 부트가드가 max회 후 자동 복구 시도 → 안 되면 **공식 SW 업데이트 USB**(= /system 교체) → 안 되면 fastboot/UART → 안 되면 정비(보드) |
| 로고도 안 뜸 | 소프트 복구 불가 가능성 — fastboot/UART/정비 |

## 핵심

부트가드는 **그물**이지 보장이 아니다. **공식 SW 업데이트 USB + recovery 진입 확인**이 소프트 벽돌의 실질 백스톱이고, 하드웨어/부트로더 손상은 물리 정비뿐이다. 이 체크리스트를 끝내기 전엔 실차에 올리지 않는다.
