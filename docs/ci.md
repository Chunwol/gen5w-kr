# 빌드와 릴리스

사용자는 [Releases](https://github.com/Chunwol/gen5w-kr/releases)에서 기본형 ZIP을 받습니다.

## 빌드 환경

JDK 17, Python 3.12, Android SDK 36, build-tools 36.0.0, NDK 27.2.12479018, mksh, GCC, QEMU를 사용합니다.

소스가 모두 커밋된 깨끗한 checkout에서 실행합니다.

```sh
bash tools/build-all.sh
```

기본형 설치 ZIP, 대응 소스와 체크섬은 `dist/`에 생성됩니다. 개별 개발 빌드는 각 도구의 도움말을 참고하세요.

## CI

`main` 변경과 Actions 수동 실행에서 전체 빌드·셸·JVM·ARM·산출물 검사를 묶어 실행합니다. README·기여·보안 안내만 바뀌면 생략합니다. 설치 ZIP에 포함되는 문서 변경은 새 빌드에 반영합니다. 같은 브랜치의 이전 실행은 취소합니다.

CI에는 제조사 파일, 개인 차량 정보나 영구 서명 키를 넣지 않습니다. APK는 실행마다 임시 키로 서명합니다. 검증 항목은 [검증 범위](validation.md)를 참고하세요.

## 릴리스 등록

1. **Build and verify**가 성공한 실행 번호를 확인합니다.
2. **Publish release**를 수동 실행하고 태그와 CI 실행 번호를 입력합니다.
3. 등록된 기본형 ZIP과 소스, `RELEASE-SHA256SUMS`를 확인합니다.

릴리스 작업은 성공한 main 빌드인지, 파일 체크섬과 설치본과 대응 소스의 코드 커밋이 일치하는지 검사합니다. 검증한 빌드를 다시 컴파일하거나 전체 시험을 반복하지 않습니다. 기존 태그는 덮어쓰지 않습니다.

공개 전 검토용 파일은 초안 릴리스로 보관합니다. 기존 배포본의 내용을 바꿀 때는 새 버전을 사용합니다. CI artifact는 14일만 보관하므로 릴리스 배포 파일과 구분합니다.
