# 버전 교체와 이전 설치 복원

> 차에 올리는 설치본은 점검·유선 안전판·무선 안전판뿐입니다. 기본형과 USB Wi-Fi 동글형은 부팅 필수 파일(`services.odex`·`SystemUI.odex`·`libhardware_legacy.so`)을 바꾸므로 실험실 전용이며, 설치기가 거부합니다. 아래 전환 기준은 모의 시험과 이전 설치 복원에만 해당합니다.

기본형과 USB Wi-Fi 동글형은 `build.py --lab`으로만 빌드할 수 있습니다. 순정 주의 안내와 지원 조건은 각 패키지의 검사 결과에 따릅니다. 화면을 완전히 생략하는 구성은 개인 로컬용이며 공개 소스·CI·릴리스에 포함하지 않습니다.

USB Wi-Fi 동글판의 실제 동작은 검증되지 않았습니다. 드라이버 빌드만으로 차량 Wi-Fi 서비스와의 연동을 보장할 수 없습니다. 설치기는 지원하지 않는 무선 방식을 선택하면 기존 설치를 바꾸기 전에 중단합니다.

파일 소유권 기록이 없는 이전 동글 설치나 등록이 사라지고 백업만 남은 동글 설치는 자동 교체를 중단합니다. 이전 설치 파일을 임의로 제거하지 말고 백업을 보존해 지원을 요청하세요.

## 이전 개인용 구성에서 기본형으로

설치 등록과 원본 백업이 남아 있으면 기존 안내 생략 설정을 복원한 뒤 기본형을 적용합니다. 복원 전용 검사 자료만 기본형에 포함하며 생략 기능을 새로 설치할 수는 없습니다. 새 구성 적용에 실패하면 전환 전 패키지와 상태로 원복을 시도합니다.

차량 초기화로 개인용 패키지 등록이 사라지고 시스템 백업만 남았다면 자동 전환을 중단합니다. 이전 구성과 복원 경로를 확인하기 전에는 설치를 진행하지 않습니다.

## 공통 기준

1. 새 패키지·기기 조건과 기존 구성의 복원 자료를 먼저 확인합니다.
2. 설치 잠금 아래 기존 패키지와 상태를 보관합니다. 처음 저장한 순정 원본은 덮어쓰지 않습니다.
3. 무선 방식을 바꿀 때는 기존 무선 세션을 종료하고 소유한 변경을 복원한 뒤 새 방식을 적용합니다.
4. 실패하면 전환 전 구성으로 함께 되돌립니다. 원복도 실패하면 백업과 복구 필요 상태를 남기고 재부팅하지 않습니다.
5. 일반 핫스팟 정보와 CarPlay 접속 정보는 분리하고 로그·진단 문서에 기록하지 않습니다.

동글판을 추가할 때에는 내장형과의 양방향 교체, 같은 버전 재설치, 실패·전원 중단·초기화 후 복원을 확인해야 합니다. 드라이버 로딩과 실제 무선 연결은 별도의 차량 확인이 필요합니다.
