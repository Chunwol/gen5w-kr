# 버전 교체와 이전 설치 복원

공개 배포는 내장 Wi-Fi용 기본형 하나입니다. 순정 안내 화면과 안전 조건을 유지하고, 지원 사양의 자동 전환 대기 시간만 10초에서 3초로 줄입니다. 화면을 완전히 생략하는 구성은 개인 로컬용이며 공개 소스·CI·릴리스에 포함하지 않습니다.

USB Wi-Fi 동글판은 개발 중입니다. 드라이버 빌드만으로 차량 Wi-Fi 서비스와의 연동을 보장할 수 없어 설치 파일을 배포하지 않습니다. 기본형 설치기도 아직 제공하지 않는 무선 방식을 선택하면 기존 설치를 바꾸기 전에 중단합니다.

## 이전 개인용 구성에서 기본형으로

설치 등록과 원본 백업이 남아 있으면 기존 안내 생략 설정을 복원한 뒤 기본형을 적용합니다. 복원 전용 검사 자료만 기본형에 포함하며 생략 기능을 새로 설치할 수는 없습니다. 새 구성 적용에 실패하면 전환 전 패키지와 상태로 원복을 시도합니다.

차량 초기화로 개인용 패키지 등록이 사라지고 시스템 백업만 남았다면 자동 전환을 중단합니다. 개인 로컬 번들로 먼저 원복한 뒤 기본형을 설치하세요. 이전 구성을 되살릴 수 없는 상태에서 설치를 진행하지 않습니다.

## 공통 기준

1. 새 패키지·기기 조건과 기존 구성의 복원 자료를 먼저 확인합니다.
2. 설치 잠금 아래 기존 패키지와 상태를 보관합니다. 처음 저장한 순정 원본은 덮어쓰지 않습니다.
3. 무선 방식을 바꿀 때는 기존 무선 세션을 종료하고 소유한 변경을 복원한 뒤 새 방식을 적용합니다.
4. 실패하면 전환 전 구성으로 함께 되돌립니다. 원복도 실패하면 백업과 복구 필요 상태를 남기고 재부팅하지 않습니다.
5. 일반 핫스팟 정보와 CarPlay 접속 정보는 분리하고 로그·진단 문서에 기록하지 않습니다.

동글판을 추가할 때에는 내장형과의 양방향 교체, 같은 버전 재설치, 실패·전원 중단·초기화 후 복원을 확인해야 합니다. 드라이버 로딩과 실제 무선 연결은 별도의 차량 확인이 필요합니다.
