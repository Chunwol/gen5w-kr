# 범용판 실차 한 방문 검증

현재 후보는 **실차에 적용된 적 없는 일회 시험판**이다. PC 통과는 차량 안전·무선 연결·HUD 성공을 뜻하지 않는다. 실제 명령과 경로는 [후보 절차](portable-candidate.md)의 해당 단계를 따른다. 기존 rc.1q USB와 복구 자료는 보존한다.

1. **진입 조건 확인**: 정차·안정 전원, 차량 신원, 유선 root 연결, NEMESIS 1.16.7 이상, 기존 패키지 충돌 없음, 정상 순정 상태를 확인한다. 일반 시동과 실제 콜드 재시작 전후 boot_id/uptime을 비교한다. root 접근이나 콜드 재시작 방법이 불명확하면 진단만 하고 적용하지 않는다.
2. **순정 기준점**: 새 디렉터리에 snapshot을 남기고 wifi_ap_on=0, 순정 유선 연결 지연·오디오·내비·HUD·카메라·메모리를 기록한다. 영속 logcat과 패닉 자료를 PC에 비공개 보존한다. null/오류를 임의로 0으로 고치지 않는다.
3. **전제 시험**: 같은 바이트 DiPO ODEX와 no-hook wrapper를 `boot.sh probe`로 시험한다. 수동 zygote 정지나 직접 mount는 하지 않는다. probe-ready와 실제 파일 매핑, 유선 기능을 확인한다. 명시 해제·검증된 콜드 재시작 후 원래 기준점으로 복원됐는지 비교한다.
4. **무선 보류 상태의 전체 시험**: NEMESIS로 설치하고 mode=trial, enabled=1, armed, 무선 보류 파일을 확인한다. 첫 콜드 부팅에서 전체 runtime과 현재 DiPO 준비를 확인한다. 호스트를 끈 채 BT 연결로 예상 밖 AP/드라이버가 생기면 중단한다. 유선·오디오·내비·HUD·카메라와 메모리를 10분 이상 관찰한다.
5. **명시적으로 무선 허용**: 정차 상태에서 보류를 해제한 뒤 무선 CarPlay, BT 인계, 오디오, 실제 HUD 방향·거리·차선과 순정 내비 전환을 확인한다. 15분 이상 유지한다. AP 시작 후 60초 이상 기다리고 다음 두 출력이 맞아야 시동 조작으로 넘어간다.

   ```sh
   /system/bin/sh "$B/ap.sh" status
   settings get global wifi_ap_on
   ```

   각각 `ap|admitted`, `0`이어야 한다. B는 실제로 확인한 설치 경로다.

6. **복귀·두 번째 시험**: 같은 boot_id의 일반 시동 복귀와 실제 콜드 부팅을 구분한다. 콜드 부팅에서 일회 시험이 소비돼 순정으로 남는 것은 정상 보호 동작이며 재접속 성공으로 기록하지 않는다. 첫 시험이 통과한 경우만 해제 후 정확한 manifest로 `arm --trial`하여 두 번째 콜드 부팅을 시험한다. 매 trial 예약은 무선을 다시 보류하므로 파일 존재를 확인한다.
7. **최종 복원**: disable, 실제 콜드 재시작, 원래 baseline 비교를 모두 통과해야 복원 성공이다. softap 프로필·새 인터페이스·모듈 경고도 검토한다. AP 미완료 기록을 지워서 통과시키지 않는다. classify/rearm은 자료를 검토하고 보관한 뒤에만 쓴다.
8. **정식 자동 적용 판단**: 위 실제 기능·성능·복원 결과를 기록한 후에만 별도 자동 모드로 전환한다. 부팅 후 자동 연결 경로는 유지된다. 다만 healthy와 AP 보호 해제 이후의 늦은 리셋은 영구 모드에서 ADB 없는 탈출을 보장하지 않으므로, 일회 시험 성공과 영구 운용 승인을 구분한다.

예상 밖 리셋·반복 크래시·긴 화면 정지·카메라/오디오/내비 이상이 있으면 이후 단계를 멈춘다. root가 살아 있으면 disable한다. 실패하면 enabled=0과 sync 후 검증된 콜드 재시작을 사용하고, 자료를 보존한다. 화면·root가 모두 없으면 일회 소비와 콜드 복원에 의존하며 임의 재시도하지 않는다. 실패한 같은 부팅의 재-arm은 차단된다.

기록에는 후보 SHA256, 차 빌드·NEMESIS 버전, 단계별 boot_id·시간·결과·메모리와 비공개 진단 경로를 남긴다. 제조사 APK/ODEX/라이브러리나 인증 자료는 공유 보고서에 넣지 않는다.
