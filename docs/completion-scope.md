# 기능과 적용 조건

| 기능 | 적용 조건과 동작 |
|---|---|
| 무선 CarPlay·Android Auto | 순정 기능과 Wi-Fi 하드웨어를 확인하고 관련 설정 적용 |
| 데이터 네트워크·핫스팟 메뉴 | 현재 지역의 기능 설정을 보존하며 활성화 |
| Bluetooth 자동 연결 | 광고된 UUID 확인, 단일 연결 관리, 재시도와 유선 우선 처리 |
| 핫스팟 정보 맞춤 | 일반 핫스팟 정보 보존, CarPlay 모드에서 별도 접속 정보 사용. 지원 원본·WPA2 설정 필요 |
| 무선 오디오 | 등록된 V035/V039 원본·의존 파일 조합에 AAC·Opus 형식 알림 적용 |
| CarPlay 및 Android Auto HUD | 1st/2nd TBT 회전·도로명·거리·차선 정보 순정 계기판 및 컴바이너 HUD 출력 |
| 안내 상태 처리 | 재탐색·지도 앱 변경·안내 종료·연결 해제 시 이전 표시 지움 |
| 특수 도로 | 고가·지하차도·옆길·IC·요금소·휴게소·회전교차로 처리 |
| 출력 복구 | 실패한 HUD 출력과 지움을 새 안내 없이 재시도 |
| Wi-Fi 클라이언트 | 기본 꺼짐, USB의 `GEN5W-WIFI-CLIENT` 파일로 명시적 선택 |
| 시동 동의 안내 | 순정 화면·안전 조건 유지, 버튼 활성화 즉시 자동 전환(순정 조건 통과 시) |
| 설치 관리 | 설치·업데이트·제거·원복과 중단 후 복구 |
| 초기화 후 복구 | 시스템에 보관한 소유 기록과 원본으로 복구 |
| 기존 설치 이관 | 등록된 패키지는 정상 이관, 불완전한 흔적도 원본/API가 맞으면 정상 설치 우선 |
| 기능별 설치·유선 전환 | 미지원 기능 자동 제외, 무선 변경 원복 후 지원되는 유선 HUD·지원되는 안내 타이머 유지 |
| 결과와 지원 요청 | 기능별 HTML 결과와 비식별 진단 문서 생성 |

지원 범위는 [차종·연식별 지원 확인표](porting.md)를 따릅니다. 내장 Wi-Fi 모듈이 없는 차량은 USB Wi-Fi 동글형을 사용할 수 있습니다. 동글형은 배포 중이지만 실차 동작은 아직 확인하지 않았고, 지원 동글(ath9k_htc)만 동작합니다. HUD 변환은 CarPlay 및 Android Auto 순정 프로젝션 연동을 모두 지원합니다.

구현과 실제 차량에서 확인한 결과는 구분합니다. 아이콘 대체 규칙과 남은 확인 항목은 [검증 범위](validation.md)에 정리합니다.
