# 사용 전 안내

Gen5W KR은 제조사와 관계없는 비공식 오픈소스 프로젝트입니다. 제조사의 승인이나 인증을 받은 제품이 아닙니다. 문서에 쓰인 제조사·차량·서비스 이름은 대상을 구분하기 위한 것입니다.

## 설치와 사용

설치 과정에서 내비게이션의 시스템 파일과 설정을 변경합니다. 차량과 소프트웨어 버전에 따라 설치 실패, 연결 불안정, 표시 오류 또는 복구 작업이 발생할 수 있습니다. 모든 차량에서의 정상 동작을 보증하지 않습니다. 설치 전 [차종·연식별 확인표](porting.md)와 복구 방법을 확인하세요.

설치와 설정은 정차 상태에서 진행하세요. HUD 길안내는 보조 정보이며, 실제 도로 상황과 교통 표지를 우선하세요. 표시가 잘못되거나 연결이 불안정하면 해당 기능의 사용을 중단하고 [되돌리기·제거 안내](beginner-guide.md#8-업데이트상태-확인되돌리기제거)를 따르세요.

## 시동 주의 안내 및 법적 고지

확인 버튼이 활성화되면 순정 자동 전환 조건을 확인해 10초 대신 바로 넘깁니다. 시스템 파일은 바꾸지 않습니다. 경고 화면과 순정 안전 조건은 유지하며, 자동 전환 조건이 맞지 않으면 수동 확인이 필요합니다.

이 화면에 표시되는 주의사항(운전 중 조작 금지, 도로교통법 준수, 전방 주시)과 이용 조건은 자동 전환 여부와 무관하게 모든 운전자에게 그대로 적용됩니다. 화면을 완전히 생략하는 구성은 공개 배포하지 않습니다. 자동 전환 기능이 법적 적합성이나 사고 시 면책을 보장하지 않습니다. 제조사 보증 적용 여부는 해당 보증 조건을 확인하세요.

## 배포와 권리

배포물에는 제조사 펌웨어와 복호화 키를 포함하지 않습니다. 외부 프로그램(NEMESIS 등)과 제조사 소프트웨어에는 각각의 이용 조건과 권리가 적용됩니다. 이 프로젝트의 라이선스는 해당 자료에 대한 이용 허락을 대신하지 않습니다. 자세한 내용은 [라이선스와 소스](licensing.md) 및 [NOTICE.md](../NOTICE.md)를 참고하세요.

소프트웨어는 관련 법령이 허용하는 범위에서 무보증으로 제공됩니다. 이 안내는 법률상 배제할 수 없는 책임을 제한하지 않습니다.

후원은 자발적인 개발 지원이며, 특정 기능의 제공이나 차량별 지원을 구매하는 대금이 아닙니다.
