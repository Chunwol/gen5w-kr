# 무선 연결과 기존 설정 복구

받은 ZIP의 내용을 USB 맨 바깥에 복사하고 차량에 꽂아 실행 확인에서 **예**를 누릅니다. 설치 시작 시 무선 지원 여부를 자동 판별합니다.

무선 기능(Wi-Fi 하드웨어)이 없으면 기존 무선 설정·오디오 보정을 원복하고 핫스팟 자동 보정·Bluetooth 자동 연결을 끕니다. Wi-Fi 확인 결과가 불확실하면 이미 검증된 기존 무선 설정은 그대로 두고, 기존 설정이 없으면 무선 기능 없이 설치합니다. 지원되는 유선 HUD·안내 자동 전환·블루링크 안내 숨기기는 각각 조건을 확인해 설치합니다. 별도 CMD나 모드 선택은 필요하지 않습니다.

원복 실패나 설치 파일 손상은 중단합니다. `GEN5W-REPORT/RESULT.html`에서 기능별 결과를 확인하고, 지원 요청에는 `ISSUE.md`를 검토 후 첨부하세요.
