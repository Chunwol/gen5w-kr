# CarPlay 핸들 통화 버튼

V035·V039의 확인된 순정 APK/ODEX 조합에 적용합니다. 통화 중 핸들 통화 버튼을 처리할 때 통화 목록에서 상태를 찾지 못하면 입력을 버리던 분기를 보완합니다.

- 상태 0~3이면 기존 순정 분기와 동작을 유지합니다.
- 상태가 음수이면 기존 HookSwitch 누름·해제 블록을 실행합니다.
- 알 수 없는 양수 상태는 기존처럼 무시합니다.
- 종료 버튼, 길게 누르기, TMU·카메라 조건과 다른 통화 버튼 분기는 수정하지 않습니다.

별도 데몬을 추가하지 않습니다. 기존 DiPO 패치 안에서 4바이트 분기 슬롯을 같은 길이의 조건 분기로 바꿉니다. 변경된 클래스의 오래된 Dalvik GC 맵을 무효화하고 체크섬을 다시 계산합니다. 순정 실행 파일은 배포하지 않습니다.

무선 CarPlay의 통화 목록 누락에 대응하기 위한 변경이며, 코드에 연결 방식 검사를 새로 넣지는 않습니다. 따라서 유선 연결에서도 상태 조회가 음수로 실패하면 같은 대체 동작을 합니다. 정상적인 유선 통화 상태 분기는 그대로지만, 모든 상황에서 영향이 없다고 보장하지는 않습니다.

이전 버전의 정확한 패치 해시는 원본 백업과 설치 소유권이 확인된 경우에만 업데이트·복원 대상으로 인정합니다. 백업이 없거나 파일이 다르면 설치를 멈추고 기존 파일을 보존합니다. 제거 시에는 검증한 순정 원본으로 복원합니다.

PC에서 분기·원본 식별·업데이트·제거를 확인했습니다. 실차에서는 무선 수신 응답, 핸들 종료 버튼의 거절·종료, 유선 통화, TMU 통화, 짧게/길게 누르기를 확인해야 합니다. 코드 검사만으로 통화 성공을 확정하지 않습니다.
