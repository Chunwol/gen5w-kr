# V039 HUD 코드 대조

범위는 V039의 순정 `ClusterService`와 `NavigationCluster`, GPM·내비 수신기 및 현재 앱 코드입니다. 다른 펌웨어와 실차 표시 결과는 별도 확인이 필요합니다. 순정 바이너리나 디컴파일 코드는 배포하지 않습니다.

## 고속도로 표시

`ClusterService.updateTPHighwayMode`는 프레임을 만든 뒤 `NaviCluster.updateTPHighWay`에 전달합니다. 이 메서드는 데이터를 저장하고 메시지 `0x11`을 예약합니다. `ClusterHandler`의 해당 분기는 `NaviCluster.sendTPHighWay`를 호출하며, V039의 이 메서드는 아무 작업 없이 반환합니다.

따라서 프레임 생성만으로 MICOM 송신 성공을 판단할 수 없습니다. 이 경로의 호출을 다시 넣어도 V039 고속도로 표시 지원이 완성되지는 않습니다. 앱은 이 경로를 사용하지 않으며, 고속도로 전용 표시를 지원한다고 안내하지 않습니다. 회전·거리·차선은 별도 경로입니다.

검증 시 최적화된 호출 슬롯은 `Object → ClusterBase → NaviCluster` 상속 순서로 대조했습니다. 슬롯 145는 `updateTPHighWay`, 슬롯 77은 `sendTPHighWay`입니다.

## km 거리 소수점

`NaviCluster.updateTBTInfo`는 거리의 정수부와 소수 첫째 자리를 따로 포장합니다. 소수 첫째 자리는 `(distance × 10) % 10`으로 계산해 바이트 7의 하위 4비트에 기록하고, 단위는 바이트 6에 기록합니다.

앱의 1,900m 입력은 `1.9f`, km 단위로 전달됩니다. 정수부가 1로 변환된다는 사실만으로 1km로 잘린다고 판단할 수 없습니다. 실차에서 실제 표시 형태는 확인해야 합니다.

## 순정 사운드

순정 `NaviETCReceiver`의 `SOUND_ON` 분기는 사운드 플래그와 엔진 상태를 바꿉니다. HUD 카메라 정보에만 한정된 제어가 아닙니다. 앱은 자동 음소거 해제 요청을 제거했습니다. 통화·사용자 음소거·순정 프로젝션의 사운드 정책을 앱이 덮어쓰지 않습니다.

실차 확인 항목은 통화 중 소리, 1~2km 거리, 순정 내비와 프로젝션 전환, AA 연결 종료 후 표시입니다. 코드 검사나 CI 통과는 이 항목들의 실차 성공을 뜻하지 않습니다.
