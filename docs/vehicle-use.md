# Gen5W KR 통합본 사용

처음 설치한다면 [엔지니어링 모드부터 시작하는 안내](beginner-guide.md)를 먼저 읽으세요. USB 번들에서는 `처음설치.md`로 제공합니다.

비공식 프로젝트로 설치 시 시스템 파일과 설정이 변경됩니다. 설치 실패·연결 불안정·표시 오류·복구 작업이 발생할 수 있으며 정상 동작을 보증하지 않습니다. 설치와 설정은 정차 상태에서 진행하고 HUD보다 실제 도로 상황과 교통 표지를 우선하세요. 법률상 배제할 수 없는 책임을 제한하지 않습니다.

NEMESIS가 설치된 Gen5W용입니다. V035/V039 순정 파일의 정확한 해시와 Wi-Fi 하드웨어를 검사하며, 맞지 않으면 적용을 거부합니다. 제조사 파일은 이 압축파일에 없습니다.

1. [릴리스](https://github.com/Chunwol/gen5w-kr/releases)에서 기본형 ZIP(`gen5w-kr-standard.zip`)을 받아 풀고 그 **내용**을 USB 루트에 복사합니다. 순정 화면·안전 조건을 유지하고 확인 버튼이 활성화되면 순정 조건을 확인해 바로 넘깁니다.
2. 정차 상태에서 USB를 꽂아 Manager를 열고 **Run USB NEMESIS.sh**를 선택합니다. 삽입만으로 설치하지 않습니다. 정상 설치 후 한 번 재부팅합니다. 제한 복구만 수행한 경우에는 재부팅하지 않습니다.
3. iPhone에서 차량과 Bluetooth 페어링을 합니다. 이미 페어링했다면 다시 연결합니다. 무선 CarPlay 연결 요청을 허용합니다.
4. 지도 앱의 길안내를 시작하고 회전·거리·차선 표시와 음악·안내 음성을 확인합니다. 유선 CarPlay도 사용할 수 있습니다.

업데이트는 USB 루트의 `GEN5W-ACTION` 파일 첫 줄에 `update`, 이전 설치로 되돌리기는 `rollback`, 전체 제거는 `remove`, 상태 확인은 `status`를 적고 같은 실행 메뉴를 선택합니다. 파일이 없으면 설치합니다. 작업 후 해당 파일을 지우세요. 설치가 실패하면 자동 원복을 시도하며 실패 보고서는 기기의 `/data/nemesis/gen5w-kr-integrated/report`에 남습니다. `recovery-required`이면 백업을 지우지 말고 같은 번들로 복구하세요.

Wi-Fi 클라이언트는 기본 꺼짐입니다. 필요한 경우에만 USB 루트에 확장자 없는 빈 파일 `GEN5W-WIFI-CLIENT`를 만들고 설치합니다. 무선 CarPlay 사용에 필수인 설정은 아닙니다.

업데이트나 원복 과정에서 앱 설정이 초기화될 수 있습니다. 기능별 확인 범위는 [검증 안내](validation.md)를 참고하세요.

작업 후 USB의 **GEN5W-REPORT/RESULT.html**에서 기능별 결과를 확인할 수 있습니다. 다른 차종·펌웨어의 실패는 **ISSUE.md**를 검토 후 지원 요청에 첨부하세요. 기존 설치 상태에 따른 이관·핫스팟 복구는 자동으로 분기하며, 핫스팟만 복구한 상태를 전체 설치 완료로 표시하지 않습니다.

## 무선 미지원 차량

설치기가 처음에 자동 판별합니다. 무선 장치를 확인하지 못하면 새 설치는 유선 기능으로 진행합니다. 이미 설치한 무선 설정과 복구 기록이 정상이고 장치 확인만 불확실한 경우에는 기존 무선 설정을 유지합니다. 기록이 손상됐으면 설치를 중단합니다. 결과는 `GEN5W-REPORT/RESULT.html`에서 확인하세요.

내장 Wi-Fi 모듈이 없는 차량은 USB Wi-Fi 동글판을 시도해 주세요. 동글판은 개발 중이며 배포 후 시도할 수 있습니다. 동글과 차량 드라이버의 호환 확인이 필요합니다.

## 핫스팟과 CarPlay 무선 연결

일반 핫스팟과 CarPlay는 접속 정보를 따로 사용하지만 Wi-Fi 장치 하나를 공유합니다. 두 AP가 동시에 켜지는 기능은 아닙니다. CarPlay 연결 시 일반 핫스팟이 중단될 수 있습니다.

시스템 파일(`services.odex`)은 바꾸지 않습니다. 무선 연결을 시작할 때 순정 Wi-Fi 기능으로 CarPlay 이름·암호를 넣어 핫스팟을 켜고, 켜진 직후 일반 핫스팟의 이름·암호를 원래대로 다시 저장합니다. 일반 핫스팟이 WPA2가 아니거나 공장용 보안 재정의 설정이 있으면 AP를 변경하기 전에 연결을 중단합니다. 임의로 보안 설정을 바꾸지 않습니다.

초기 설치 시 CarPlay 접속 정보나 Wi-Fi 서비스가 아직 준비되지 않았더라도 지원 원본 검사를 통과하면 설치를 진행합니다. 실제 무선 시작은 재부팅 후 유효한 접속 정보가 준비된 때에만 시도합니다.
