# 순정 복원 전용 USB

`GEN5W-ACTION=stock-recover`는 이전 버전 패키지를 다시 설치하는 `rollback`과 다르다. 현재 등록된 우리 패키지를 제거하고, 검증된 번들의 제거 훅으로 원본 복원을 확인한다. 기존 트랜잭션의 `prior` 스냅샷은 보존하며 재설치하지 않는다.

USB 순정 복원은 USB 매니페스트와 모듈 검사를 직접 수행한다. 사용하지 않는 차내 앱 복구 도구의 세대 교체가 선행 조건이 아니다. 일반 설치에서 도구 교체가 필요한 경우에는 검증된 루트 전용 캐시 부모 아래의 이전 세대·중단된 준비 폴더를 삭제 없이 격리하고, 검증한 새 도구를 비공개 권한으로 교체한다. 심볼릭 링크의 대상이나 원본 복원 스냅샷은 변경하지 않는다.

읽기 전용 시스템 마운트, 부트가드 정리, 서비스 보류 해제와 필수 결과 저장을 확인한 뒤에만 완료 및 재부팅으로 진행한다. 실패하면 `recovery-required`와 재부팅 억제를 유지한다. 알 수 없는 재마운트 실패는 무시하지 않는다.

현재 차량처럼 NEMESIS 1.16.3인 경우 순서는 다음과 같다.

1. 순정 복원 전용 USB 실행, 결과 확인, 완전 재부팅.
2. 공식 NEMESIS 업데이트 전용 USB 구성으로 변경하여 별도 업데이트 및 재부팅.
3. 새 설치 키트로 변경하여 설치.

지원 버전은 확인된 NEMESIS 1.16.4–1.16.7이다. 구버전·알 수 없는 버전의 정상 설치는 거절한다. 구버전 순정 복원 성공 후에는 `GEN5W-ACTION=status`로 바뀌며 설치로 자동 전환하지 않는다. 플랫폼 업데이트와 앱 키트의 루트 `NEMESIS.data`를 섞지 않는다.

지원 버전에서 설치 요청 시 복구 중 상태라면 먼저 순정 복원을 실행한다. 복원 후 같은 부팅에서의 설치는 거절한다. 설치 및 이전 상태 자동 복구가 모두 실패한 경우 순정 복원을 한 번 시도하되, 최초 설치 실패 코드와 로그는 그대로 남긴다.

이 기능은 공장 초기화나 제조사 펌웨어 복원이 아니다. 우리 패키지의 소유권·원본이 검증되지 않으면 거절하며, PC 회귀시험 통과는 실차 복구 성공을 보장하지 않는다.
