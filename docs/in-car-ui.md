# 차 안 화면 (INFO / ONOFF / LOG / 관리, v0.3.47)

코어 앱(`Gen5W KR`)에 화면이 하나 생겼습니다. 무선이 지금 어떤 상태인지, 안 될 때 왜 안 되는지, 모든 Gen5W KR 패키지의 최근 기록을 한국어로 보여 줍니다. **읽기 전용입니다.** 이 화면은 아무것도 바꾸거나 쓰지 않고, 화면이 열리지 않아도 무선과 HUD는 그대로 동작합니다. ONOFF(기능 켜기/끄기)와 관리(제거)는 다음 버전에서 만듭니다.

## 구성

```
uilog 서비스 (root, 코어 패키지, 15초마다)
   모든 gen5w 패키지 서비스 로그 + gen5w logcat
        ↓ 용량 상한과 개인정보 거르기
   /data/nemesis/gen5wkr.ui/status   (상태, key=value)
   /data/nemesis/gen5wkr.ui/log      (최근 기록, "출처|원문")
        ↓ 읽기만
코어 앱의 화면 (INFO / ONOFF / LOG / 관리)
```

`/data/nemesis/gen5wkr.ui`는 root 소유 폴더입니다. root가 앱이 소유한 폴더에는 쓰지 않습니다(앱이 경로를 링크로 바꿔치기할 수 있어서).

## 용량 상한 (시스템이 넘치지 않도록)

| 항목 | 상한 |
|---|---|
| 원본 로그 파일 하나 | 128KB를 넘으면 읽지 않고 "로그가 너무 커서 건너뜀" 한 줄만 |
| 패키지 로그 하나당 | 최근 25줄 |
| logcat | 최근 40줄 |
| 한 줄 길이 | 200자 |
| `log` 파일 전체 | 200줄(약 40KB) |
| 앱이 읽는 양 | `status` 16KB·50줄, `log` 64KB·300줄 |
| 임시 파일 | 쓴 뒤 `mv`로 교체하고 남기지 않음 |

로그를 모을 때 MAC 주소, SSID, 비밀번호, 일련번호, VIN 등이 든 줄은 버립니다(USB 진단과 같은 목록).

## 언어

로그 파일과 진단 파일의 원문은 영어 코드(`FAIL bridge:`, `WAIT bridge:` 등) 그대로입니다. 설치기와 테스트, 진단 도구가 이 접두어를 읽기 때문입니다. **화면에서만** 한국어로 보여 주고, 번역 표에 없는 줄은 원문 그대로 보입니다.

## 시간 기준

`status`의 `ts`는 부팅 후 초(`/proc/uptime`)입니다. 차 시계가 맞지 않아도 되고, 지난 부팅의 낡은 파일은 "이전 부팅 때의 기록"으로 표시됩니다. 60초 넘게 갱신되지 않으면 "기록이 오래됨"으로 표시합니다.

## 차에서 확인할 것 (차에서 확인 전)

1. 설치가 끝난 뒤 앱 메뉴에 `Gen5W KR` 아이콘이 보이는지. 이 유닛의 런처가 새 앱을 보여 주는지는 아직 확인하지 못했습니다.
2. 안 보이면 NEMESIS Manager의 My Packages에서 `Gen5W KR - CarPlay HUD`를 열어 실행해 보세요.
3. INFO가 값을 보여 주는지. **"상태를 읽을 수 없음"이 뜨면** `/data/nemesis/gen5wkr.ui`를 이 앱이 읽을 권한이 없는 경우일 수 있습니다(`/data/nemesis`의 권한은 아직 확인하지 못했습니다). 그때는 USB 진단(`GEN5W-ACTION`에 `diag`)을 저장해 주세요. 진단에 이 폴더와 파일의 권한이 들어갑니다. 다음 버전에서 시스템 권한 도우미로 읽는 방식으로 바꿉니다.
4. LOG 탭에서 출처별 한국어 문장이 보이는지.

## ONOFF 스위치 (v0.3.47)

```
화면(코어 앱) --요청 파일--> root 수집 서비스 --표식 파일--> 각 패키지 서비스
 files/ui-request           /data/nemesis/gen5wkr.ui-<이름>-off
```

| 스위치 | 표식 | 끄면 |
|---|---|---|
| 무선 | `gen5wkr.ui-wireless-off` | 무선 감독이 호스트를 띄우지 않음 (유선은 그대로) |
| 시동 안내창 | `gen5wkr.ui-timer-off` | 닫기 요청을 보내지 않음 (순정 10초) |
| 블루링크 | `gen5wkr.ui-bluelink-off` | 저장한 원래 값을 한 번 되돌림 |
| HUD | 앱 폴더 `hud-disabled` | HUD 서비스가 시작하지 않고 끝남 |

- 요청 파일은 8줄까지만 읽고 정해진 단어 외에는 무시합니다. 링크이면 읽지 않습니다.
- 표식 반영은 최대 약 2초, 화면의 상태 표시는 최대 약 15초 뒤입니다. 그 사이에는 누른 상태를 먼저 보여 줍니다.
- 설치기의 유선 전용 표식과 재시작 보호 표식이 있으면 무선 스위치는 잠깁니다. 재시작 보호는 부팅 반복 방지용이라 화면에서 풀지 않습니다.
- 차에서 확인 전: 앱이 `/data/nemesis/gen5wkr.ui`를 읽는지, root 서비스가 앱 폴더의 요청 파일을 읽는지(`/data/data/kr.gen5w.core/files/ui-request`), 각 스위치가 실제로 동작하는지.
